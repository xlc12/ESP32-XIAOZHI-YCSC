# CI130X UART 协议速查

## 帧格式

```
[0..3]   magic     0x5A5AA5A5（小端）
[4..5]   version   0x0100
[6..7]   type      命令/事件类型（小端）
[8..9]   length    payload 字节数（小端）
[10..11] checksum  Σpayload（逐字节求和，取低 16 位）
[12..15] fill      0x12345678
[16..]   payload
```

要点：

- 接收侧必须容忍粘包与断包：先找 magic，再等齐 16 字节头，按 `length` 收完 payload。
- checksum 不含帧头，只累加 payload。
- 应答与事件共用同一条通道，靠 `type` 区分。

## 命令（ESP32 → CI）

| 名称 | 码 | payload | 说明 |
|---|---|---|---|
| 开始录音 | 0x011A | 无 | 置 `is_always_iis_flag`，I2S 持续输出 PCM |
| 停止录音 | 0x011B | 无 | 清 `is_always_iis_flag` |
| 播放窗口 | 0x0220 | 1 字节，1=开 0=关 | 控制 CI 是否允许播放 |
| 音量 | 0x0117 | 1 字节，1~7 | 音量档位 |
| 退出唤醒 | 0x010D | 1 字节，1=带提示音 0=静音退出 | 强制退出唤醒态 |
| 唤醒态超时 | 0x0113 | uint16 秒 | 覆盖 CI 自动退出时间，不能为 0 |
| 系统就绪查询 | 0x0601 | 无 | 一般由 CI 主动上报 |

## 事件（CI → ESP32）

| 名称 | 码 | 含义 |
|---|---|---|
| WAKE_UP | 0x0102 | 唤醒词触发，可能重复上报 |
| VAD_START | 0x0108 | 检测到人声 |
| PCM_FINISH | 0x0106 | 一句话结束（仅通知，不停传输） |
| EXIT_WAKE_UP | 0x0109 | 退出唤醒态 |
| SYS_READY | 0x0601 | 就绪，上电或复位时上报 |

## 应答

统一 `0x0801`，payload 三字节：

```
[0] type 低字节
[1] type 高字节
[2] 1 = 成功，2 = 失败
```

匹配时按 `type` 找回对应请求。

## 发送注意事项

- 在接收任务里**不要**同步等待应答（会自锁），只做记录或置标志。
- 默认应答超时 300 ms；若调用方是音频任务，务必改用不等待模式。
- 严格串行化：两次同步交叉会出现「期望值与已生效值错位」。
