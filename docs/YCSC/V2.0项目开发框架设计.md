# 1、板型适配与切换

## 1.1板型编译

1）编译，分两种

* 手动配置 menuconfig ，比较稳定， 每个板型都需要有自己的 config.josn 文件，将该板型的自定义配置记录在此，根据该文及去配置menuconfig。
* 使用 python scripts/release.py ，比较慢，最好每次都要完全把 build 文件夹删除，而且可能会导致配置误增，所有最好把所有常用的SDK配置都写在 config.josn ，做好相关注释和是开关配置。

2）板型切换

清除 build 文件夹

↓

python scripts/release.py + 板型（config.json中的name字段）

python scripts/release.py ycsc-esp32s3-8311-test
