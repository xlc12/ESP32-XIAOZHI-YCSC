# assets分区

## 分区生成和烧录

**生成流程**

plainText
配置阶段
↓
读取 sdkconfig
↓
调用 build_default_assets.py
↓
收集资源文件
├─ SR 模型（wakenet/multinet）
├─ 文本字体
├─ Emoji 集合
└─ 额外文件
↓
生成 index.json
↓
打包成 assets.bin
↓
输出到 build/generated_assets.bin

**烧录流程**
在menuconfig中 Xiaozhi Assistant --> Flash Assets配置
选择烧录方式
├─ FLASH_DEFAULT_ASSETS → 构建默认 assets，烧录预编译的默认 assets
├─ FLASH_CUSTOM_ASSETS → 使用自定义 assets，本地文件： assets.bin（相对于项目目录）；远程 URL： http://your-server.com/assets.bin
├─ FLASH_EXPRESSION_ASSETS → 构建表情 assets
└─ FLASH_NONE_ASSETS → 跳过烧录，不烧录任何 assets 到 Flash
↓
esptool 烧录到 assets 分区

## 分区在线网络更新

通过https通信下载服务器上的assets.bin

主要流程：在xiaozhi.me网页端配置唤醒词、表情和字体等资源
↓
生成assets.bin
↓
点击烧录到设备
↓
此时服务端会调用侧端MCP工具：AddUserOnlyTool，先是调用 self.assets.set_download_url 上传固件url，然后再调用 self.reboot 重启设备
↓
设备重启后跑到 CheckAssetsVersion() 中，然后判断 download_url 是否为空，不为空则进行下载。
